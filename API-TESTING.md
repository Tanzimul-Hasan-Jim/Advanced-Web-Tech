# API Testing Guide

Base URL: http://localhost:3000

| Method | Endpoint | Purpose |
|---|---|---|
| GET | /course | Get all courses |
| GET | /course/1 | Get course by ID |
| POST | /course | Create a course |
| PUT | /course/1 | Update a course |
| PATCH | /course/1 | Partially update a course |
| DELETE | /course/1 | Delete a course |
